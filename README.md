# Vesper

Worldbuilding project for a super-Earth around a mid-K dwarf: 1.2 Earth radii,
1.5 Earth masses, a 30-hour day, 32 degrees of obliquity, and a 190-day year
around a K2.5V star.

Geography is generated by a fork of World Orogen at
`/home/cfutro/git/planet_heightmap_generation`; climate is simulated with
ExoPlaSim. Other components will sit alongside them.

## Layout

| Path | Contents |
| --- | --- |
| `config/planet.yaml` | canonical planet, star, orbit, and atmosphere parameters |
| `source/` | World Orogen exports, canonical and read-only |
| `exoplasim/` | the ExoPlaSim climate component |
| `requirements.txt`, `.venv/` | shared Python 3.12 environment |

## `source/`

Four exports of seed 16236323 (2.5M mesh regions, endorheic basins preserved,
lithology-modulated erosion), all built from the same terrain:

- `exoplasim-T42/` — 128x64 Gaussian, plus the native `raw/` mesh
- `exoplasim-T63/` — 192x96 Gaussian
- `exoplasim-T85/` — 256x128 Gaussian
- `grid-512x256/` — 512x256 uniform, for mapping
- `maps/` — equirectangular PNGs, from an older 510k-region build of the same
  seed and not interchangeable with the exports above

Each export carries `manifest.json` describing every field, `README.txt`,
`grid/*.bin`, and a CF-1.8 `planet.nc` with 105 fields: elevation, land mask,
plates and their kinematics, boundary types, stress, distance fields, lithology,
hydrology, closed basins, and sub-grid orography. The fork's `tools/README.md` is
the format reference.

Weight by `grid/gauss_weights.bin` on the Gaussian grids or by `cos(lat)` on the
uniform grid. `cell_area` in the gridded output is a mesh diagnostic, not the
cell's area.

## `exoplasim/`

Converts the geography to ExoPlaSim boundary conditions and runs reproducible
climate experiments. See `exoplasim/README.md` for the workflow and results and
`exoplasim/notes/parameter-decisions.md` for the reasoning behind every
parameter.

Completed so far: a T42 stellar-flux sweep at 0.85, 0.90, and 0.95 S-Earth, and
a pair of 8-Earth-year stellar activity cycle experiments. The 0.95 case reaches
292 K and is the strongest candidate for the intended habitable regime.

These results were produced from an earlier revision of the world map. They
remain physically valid but do not describe the geography now in `source/`.
