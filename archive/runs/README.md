# Archived runs

Derived products from runs this project no longer models: either the
terrain under them was superseded, or the climatology below them was,
which by CLAUDE.md rule 7 makes them worthless rather than stale. The
raw NetCDF is gone -- it was 50 GB. What remains is what anything ever
cited: the manifest, the convergence assessment, the climate series,
and the namelists.

`INDEX_ENTRY.json` in each directory is that run's row from
`exoplasim/runs/INDEX.json` at the time it was archived, so a result
computed from one of these stays readable and datable without the
output being present. The row also stays in `INDEX.json` itself,
marked `payload_present: false`: since world-ww6z that file is a
ledger of every run that has EXISTED rather than a listing of what is
on disk, so this stub is no longer the only thing standing between a
deleted run and a dead string.

A `RECONSTRUCTED.json` is not an `INDEX_ENTRY.json` and is named apart
on purpose: it is identity pieced back together from surviving
artifacts for a run that was never registered at all, it cites the
artifact behind every field, and it lists what is unrecoverable.

`RECORDLESS.json` is the enumeration of the runs that got neither: run
ids this tree cites that no record can identify. It is generated by
`python exoplasim/scripts/index_runs.py --recordless` and shrinks by
itself as identity is recovered, so it measures the remaining damage
rather than describing it. `notes/audits/run-identity.md` is the
finding.
