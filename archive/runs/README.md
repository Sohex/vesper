# Archived runs

Derived products from runs this project no longer models: either the
terrain under them was superseded, or the climatology below them was,
which by CLAUDE.md rule 7 makes them worthless rather than stale. The
raw NetCDF is gone -- it was 50 GB. What remains is what anything ever
cited: the manifest, the convergence assessment, the climate series,
and the namelists.

`INDEX_ENTRY.json` in each directory is that run's row from
`exoplasim/runs/INDEX.json` at the time it was archived, so a result
computed from one of these stays readable and datable without the
output being present.
