# Archived runs

Derived products from runs on superseded terrains. The raw NetCDF is
gone: it described a world this project no longer models, and it was
50 GB. What remains is what anything ever cited -- the manifest, the
convergence assessment, the climate series, and the namelists.

`INDEX_ENTRY.json` in each directory is that run's row from
`exoplasim/runs/INDEX.json` at the time it was archived, so a result
computed from one of these stays readable and datable without the
output being present.

Archived 2026-08-16.
