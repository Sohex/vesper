# Closed tasks

Every task that has been finished or abandoned, with the reasoning that closed
it. Moved out of `TASKS.md` so that file shows only what is left, and kept
rather than deleted for two reasons.

**IDs are never reused.** A closed id has to stay findable, because commits,
notes and audits cite it. Search here first when an id in a commit message does
not appear in `TASKS.md`.

**The reasoning is the point.** A `wontfix` records why something that looked
like work turned out not to be, and several here reverse an earlier conclusion.
Deleting them would lose the argument and invite the same task being opened
again.

Same conventions as `TASKS.md`: one line per task, every task cites the document
that justified it, and the closing note says what was actually done rather than
that it was done.
