# The derived-structure prose audit

A corpus-wide sweep, 2026-08-19, for what is now
`docs/src/practice/failure-modes.md` class 24: derived summaries -- counts,
partitions, pairings, exception claims -- that fail against their own
primitives. Six fresh-context reviewers over the whole documentation corpus;
fifty-one findings, every one either fixed or settled from surviving
artifacts and git history. The instances and their resolutions are in git
(commits 53bc34b and e0ae785).

One reading stands as accepted rather than fixed: failure-modes' "those are
the four that work" is exhaustive only if its comparison table's
same-quantity row is read under "a quantity the other side already knows"; it
can be, so it stays.
